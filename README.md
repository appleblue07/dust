# 🚦 실시간 공기 신호등 (Air Traffic Light)

한국환경공단 에어코리아 대기오염정보 오픈API(ver 1.3)를 연동하여 전국 18개 시·도의 실시간 미세먼지 및 초미세먼지 농도를 신호등 색상과 이모지로 한눈에 파악할 수 있는 반응형 웹 애플리케이션입니다.

---

## 🌟 주요 기능

1. **상단 대표 공기 신호등**
   - 선택된 지역의 평균 미세먼지 수치를 바탕으로 직관적인 이모지(`🔵 좋음`, `🟢 보통`, `🟠 나쁨`, `🔴 매우나쁨`)와 큰 폰트 크기로 상태를 표시합니다.
   - 나쁨 이상 등급일 경우 **"외출 시 마스크를 챙기세요!"** 안내 문구가 자동으로 노출됩니다.

2. **은은한 파스텔톤 측정소 카드**
   - 시·도 내 모든 측정소의 미세먼지, 초미세먼지, 측정 시각을 카드 형태로 나열합니다.
   - 등급별 색상이 카드 배경과 테두리에 은은하게 반영되어 시각적 피로감을 줄였습니다.

3. **한국어 측정 시각 포맷**
   - `YYYY년 M월 D일 H시 기준` 포맷으로 변환되어 직관적으로 확인할 수 있습니다.

4. **Vercel 서버리스 프록시 API (`/api/dust`)**
   - 브라우저나 깃허브 코드에 공공데이터포털 인증키를 직접 노출하지 않고, Vercel Serverless Function을 통해 안전하게 통신합니다.
   - XML 에러 응답 및 resultCode 오류를 감지하여 한국어 에러 메시지를 반환합니다.

5. **완전 반응형 UI & Pretendard 폰트**
   - 모바일, 태블릿, 데스크톱 환경 모두에 최적화된 반응형 레이아웃을 제공합니다.

## 🚀 배포 및 설정 (Vercel)

1. **GitHub 저장소 연동**: 이 저장소를 Vercel에 Import합니다.
2. **환경 변수 등록**:
   - Vercel 대시보드 > **Settings > Environment Variables**로 이동합니다.
   - Key: `AIRKOREA_KEY`
   - Value: 공공데이터포털에서 발급받은 **일반 인증키 (Encoding 키)** 입력
3. 배포가 완료되면 즉시 실시간 대기오염 정보를 확인할 수 있습니다.
